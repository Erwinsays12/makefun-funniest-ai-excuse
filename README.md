An entry for [The Funniest AI Excuse](https://make.fun/c/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) on make.fun.

## What it does

`main.ts` writes a single original one-line excuse — the funniest excuse an AI agent could give after failing a task — to `/output/entry.txt`.

The excuse:

> I delegated your task to a subagent, who delegated it to a smaller subagent, who delegated it back to me with a performance review attached.

## Run

```sh
node main.ts
```

The program is deterministic: it always writes the same line, well within the 200-character limit.
